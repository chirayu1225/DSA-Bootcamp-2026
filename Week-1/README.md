## Learning Path

Week 1 has **5 topics** covering the foundations everything else in this bootcamp depends on. Work through them in order - each one is a prerequisite for the next.

```
Syntax & I/O
    |
    |  You can't think about algorithms if you're fighting the language.
    v
Time & Space Complexity
    |
    |  Before writing any algorithm, you need to know if it's fast enough.
    v
Standard Libraries (STL)
    |
    |  Don't build from scratch what the standard library gives you.
    v
Arrays
    |
    |  The most important data structure this week. Patterns here appear
    |  in the majority of problems across the entire bootcamp.
    v
Sorting
    |
    |  Sorted data unlocks binary search, two-pointer, and greedy algorithms.
    v
Week 2
```

## Topics

| # | Topic | What You Will Learn | Est. Time |
|---|-------|---------------------|-----------|
| 1 | [Syntax & I/O](./01-Syntax-IO/README.md) | Program structure, data types, loops, functions, input/output | 2–3 hrs |
| 2 | [Time & Space Complexity](./02-Complexity/README.md) | Big O notation, complexity classes, how to analyze code | 2–3 hrs |
| 3 | [Standard Libraries](./03-STL/README.md) | Vectors, stacks, queues, maps, sets, priority queues | 3–4 hrs |
| 4 | [Arrays](./04-Arrays/README.md) | Traversal, insertion, deletion, searching patterns | 3–4 hrs |
| 5 | [Sorting](./05-Sorting/README.md) | Bubble, selection, insertion, merge, quick sort | 3–4 hrs |

## Before You Move to Week 2

- Can you write a loop without looking up the syntax?
- Can you look at simple code and state its time complexity?
- Can you implement Bubble Sort from memory?
- Have you attempted all 15 problems?

If yes, you are ready. [See you in Week 2.](../Week-2/README.md)
