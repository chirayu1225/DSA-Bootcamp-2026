## Learning Path

Week 3 introduces the techniques that underpin the most powerful algorithms in DSA. Each topic builds directly on the previous one.

```
Recursion
    |
    |  The mental model behind trees, graphs, backtracking, and DP.
    |  Every iterative algorithm has a recursive counterpart.
    v
Divide & Conquer
    |
    |  Recursion applied to splitting problems into equal halves.
    |  This is why Merge Sort is O(n log n), not O(n²).
    v
Hashing
    |
    |  After searching efficiently (binary search, D&C), hashing gives
    |  O(1) lookup - the fastest possible. Trades memory for speed.
    v
Sliding Window
    |
    |  Two pointers + hashing combined into one powerful pattern for
    |  substring and subarray problems. The culmination of Week 3.
    v
Week 4
```
