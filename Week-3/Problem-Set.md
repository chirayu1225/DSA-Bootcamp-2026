## How to Approach These Problems

1. Open the link and read the problem carefully.
2. Solve it on your own first - minimum 20–25 minutes before looking at solutions.
3. After attempting, read the better and optimal approaches.
4. Even if your solution works: try to reduce complexity, improve readability, write cleaner logic.
5. Dry run your code on test cases. Test edge cases.
6. Write time and space complexity after every solution.
7. If stuck: draw examples, observe patterns, simplify, solve smaller cases manually.

> All selected problems are the most commonly occurring and logical. Spend sufficient time on each before moving to additional problems.
