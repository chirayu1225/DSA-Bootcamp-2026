## Learning Path

Week 2 builds directly on Week 1's sorting knowledge and introduces four patterns that show up in the majority of array, string, and search problems.

```
Prefix Sum
    |
    |  The first "trick": preprocess once, answer range queries in O(1).
    |  Mindset: trade space for time.
    v
Two Pointers
    |
    |  Use two indices moving through the array to avoid nested loops.
    |  Reduces O(n²) pair problems to O(n).
    v
Binary Search
    |
    |  Sorted data (from Week 1) lets you halve the search space at every step.
    |  Reduces O(n) search to O(log n).
    v
Strings
    |
    |  Strings are arrays of characters. All three patterns above apply
    |  directly to string problems.
    v
Week 3
```

## Before You Move to Week 3

- Can you build a prefix sum array and answer a range query in O(1)?
- Can you solve a two-sum problem on a sorted array in O(n) using two pointers?
- Can you implement binary search iteratively without looking it up?
- Can you reverse a string in-place?
