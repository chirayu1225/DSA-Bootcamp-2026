## How to Approach These Problems

1. Open the link and read the problem carefully.
2. Solve it on your own first - minimum 20–25 minutes before looking at solutions.
3. After attempting, read the better and optimal approaches.
4. Even if your solution works: try to reduce complexity, improve readability, write cleaner logic.
5. Dry run your code on the provided test cases.
6. Test edge cases: empty arrays, single elements, negative numbers, large inputs.
7. Write down the time and space complexity after every solution.
8. If stuck: draw examples, observe patterns, simplify the problem, solve smaller cases manually.

> All selected problems are the most commonly occurring and highly logical. Spend sufficient time on them to build a strong foundation before moving to additional problems.
